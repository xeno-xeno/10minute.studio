수천 개의 문학·영화·음악 작품에서 시간을 품은 문장만 골라, 1,700개의 시간 아카이브를 만들었습니다.

지금 이 순간, 누군가는 이미 당신의 시간을 예술로 남겼습니다. 하루 1,440분, 지금 이 시간에 맞는 한 문장이 떠오릅니다.

아직 비어 있는 시간도 있습니다. 한글의 선과 획으로, 더 많은 문장이 당신의 시간을 채워나갈 예정입니다.
